# Cardiovascular Disease Prediction

## Project Overview
This project uses Machine Learning to predict the presence of heart disease based on patient health-related features.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
- Logistic Regression

## Project Workflow
1. Loaded the UCI Heart Disease dataset.
2. Handled missing values.
3. Performed exploratory data analysis.
4. Created visualizations to understand the dataset.
5. Split the data into training and testing sets.
6. Trained a Logistic Regression model.
7. Evaluated the model using accuracy, precision, recall, F1-score, and a confusion matrix.
8. Tested a sample prediction.

## Results
- Model: Logistic Regression
- Test Accuracy: 86.89%
- Test Samples: 61
